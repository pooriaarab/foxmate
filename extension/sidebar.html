    Claude Code reads this tab, and you approve each change here. It sends what it reads to its own model. Set it up one time: foxbridge install --extension-id foxmate@pooriaarab.

    Tasks

    Each goal runs as a foxrunner task. If Firefox unloads the background page, the task runs again from its goal at the next wake. Nothing runs while Firefox is closed.

                  Optional modules

                  Each one is off until you turn it on.

                  Your phone gets each approval too, over an encrypted peer-to-peer link. The first answer counts. The link lives in this sidebar: keep it open.

                  Not paired.

                  The look tool sends a screenshot of the tab to a vision model in Ollama on this computer, never to a cloud model.

                  Use your own Google OAuth client id. foxvault keeps the tokens. Mail and events go to the planner as data.

                  Notices (foxnotify)

                  When a goal needs you, ends, or a schedule runs late, and no sidebar is in view, foxmate shows a notice on this computer. A click opens the tab or the approval. It never approves.

                  Type an address to see the request.

                  Payments (foxpay)

                  foxmate can pay a bill on the tab's site with test USDC on Base Sepolia (x402). Each payment waits for your Approve, with the exact amount, payee and site. A cap of 0 turns payments off.

                  foxvault keeps the key encrypted. The planner never gets it.
